Portfolio valuation

Native NEAR plus indexed fungible-token balances, valued from a separate price observation. Each read runs only when you request it. Nothing is signed or sent.

Current valuation

Select an account, then read its current valuation. Up to 40 indexed tokens are read; unpriced assets stay unavailable rather than counting as zero.

Retained observations

Only valuations that were actually read and retained are shown. Different inventory scopes are charted separately, gaps are never joined, and no return or profit figure is derived.

Select an account, then load its retained valuation observations.

Archived balances at a block

A positive mainnet block height. Balances are read from archival RPC at exactly that block.

Up to 20 exact contract accounts, separated by commas or new lines. Native NEAR is always read; contracts you do not list are not read.

Enter a block height to read the balances recorded at that block. The result covers only native NEAR and the contracts you list.
