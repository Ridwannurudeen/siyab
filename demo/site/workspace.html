Reset encrypted copy

This permanently deletes your account's encrypted copy on this Siyab origin. The encrypted data is lost. Export any work you can still open first. Browser saves and shared teams are unchanged. Sign out and sign in with NEAR again if your sign-in is five minutes old.

Use the NEP-413 signing interface in Sender or OKX Wallet. ETH-implicit (0x) accounts cannot sign in. The wallet must sign the same unlock message twice identically. Only approve this unlock message from this Siyab origin. Keep the same signing key on every device and export a local backup before changing keys.

The server sees your account, signing public key, IP address, ciphertext size, revision numbers and read and save timing. Browser saves stay on this device until you choose Save encrypted copy. Private watch matching runs while this browser is open.
